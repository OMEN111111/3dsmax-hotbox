# MaxHotbox — Maya-Style Hotbox & Marking Menu for 3ds Max 2026 / 2027

> **当前版本：`v0.1.5` (Beta 测试版)** · 适配 **Autodesk 3ds Max 2026 & 2027 (Win64)** · 兼容中/英文界面

**MaxHotbox** 是一款为 **Autodesk 3ds Max 2026 / 2027** 打造的 **Maya 风格热盒（Hotbox）与多级径向标记菜单（Marking Menu）** 插件。  
采用 **Win32 视口子类化 (`SetWindowSubclass`) + PySide6 (Qt 6.5 / 6.8) 悬浮渲染 + `pymxs`/MAXScript 解耦命令引擎 + Autodesk `.bundle` 标准打包**，在高度贴合 3ds Max 原生深灰 UI 风格的同时，实现流畅的按住、划动、悬停展开、松开即执行的 Maya 式建模交互，并支持随时一键切换回原生四元菜单（Quad Menu）。

---

## 核心功能

### 1. 多级径向标记菜单（8 方向 + 悬停子菜单 `▸` + Maya 鼠标返回上级）
在任意 3D 视口内按住以下组合键并划动鼠标，松开即执行：
- **右键 (`RMB`)**：智能上下文菜单（根据选中的是多边形、样条线还是空白视口自动切换对象/子层级/创建菜单）。
- **`Shift + 右键`**：智能建模菜单（多边形模式下按 Object / Vertex / Edge / Border / Polygon 自动切换且**统一核心肌肉记忆方位**：北=挤出 `□`、西=塌陷、西北=切割与平面、东南=石墨建模；**样条线模式下按对象 / 顶点 / 线段 / 样条三层级自动切换**，包含圆角、切角、四种顶点类型、插入顶点、拆分 `□`、分离、轮廓、修剪、布尔等全套工具）。
- **`Ctrl + 右键`**：选择转换与石墨选择菜单（转顶点/边/面/元素、随机选择、**选择相似 `□`**、原生石墨点循环/点环形、步骤循环、选多边面、硬边与共面选择）。
- **`Alt + 右键`**：视口与着色显示菜单（顶/前/左/右/后/底/透视/正交/相机视图、线框、边面、黏土着色、最大化视口）。
- **`Ctrl + Shift + 右键`**：坐标系、**Gizmo 调整中心**、枢轴与捕捉菜单（局部/世界/视图/万向节坐标、**使用轴点中心 / 使用选择中心 / 使用变换坐标中心**、仅影响轴、居中枢轴、轴到底部、Reset XForm）。
- **`Space + 右键`（Maya 空格热盒）**：参考 Maya 按住空格+右键唤出视图与快捷热盒，自动屏蔽空格松开避免误触 3ds Max 选择锁定。
- **二级悬停子菜单 (`▸`) 与防误触返回上级**：悬停在带 `▸` 按钮上约 `180ms` 自动展开子菜单；展开后**悬停中心下方的 `‹ 返回上级` 按钮**或**按住右键同时轻点左键**即可立即返回上一级菜单，且内置防重复展开锁定，移开前不会误触再次打开刚退出的子菜单。

### 2. 石墨工具整合 & 自建 PySide6 实时预览参数面板（`□` Option Box）
不依赖 Ribbon 原界面按钮，内置高频石墨工具并重构了原生 3ds Max 2026 风格实时预览悬浮面板（点击按钮右侧 `□` 唤出，取消自动还原原始选择）：
- **随机选择 (`Random Select`)**：主按钮按上次比例快选；`□` 面板支持 `1%~100%` 比例滑块、全部/当前选集范围切换与“换一批”实时预览。
- **按边数选择面 (`Select by Sides`)**：主按钮一键选多边面 `N-Gon (>4)`；`□` 面板支持三角面/四边面/多边面预设及自定义边数条件。
- **点循环 / 点环形 (`Dot Loop` / `Dot Ring`)**：直接驱动 3ds Max 原生 `PolyToolsSelect.DotLoop` / `DotRing`，与原生石墨工具 100% 一致（支持顶点/边/面与 Edit Poly 修改器），`□` 面板支持间隔 Gap (`1~20`)、圆柱端面、反向实时预览。
- **选择相似 (`Select Similar`)**：主按钮一键选拓扑/尺寸相似子对象（支持对象/点/边/面）；`□` 面板支持容差滑块 (`0%~50%`)、拓扑匹配与尺寸匹配实时预览。
- **自动平滑 & 平滑组面板 (`Auto Smooth / Smoothing Groups`)**：面层级 `自动平滑` 右侧 `□` 打开原生风格平滑组设置框，支持 `0°~180°` 角度阈值滑块、一键清除与 `1~32` 平滑组交互矩阵。
- **硬边选择 / 共面选择 (`Angle Select`)**：基于面法线夹角算法，`□` 面板支持 `1°~179°` 角度阈值实时预览。
- **五大分类修改器库（50+）**：清晰归类为 **常用修改器**、**变形修改器**（弯曲/扭曲/噪波/推力/松弛/锥化/FFD/球形化/波浪/涟漪/拉伸/倾斜/置换）、**UV 修改器**（UVW 展开/UVW 贴图/UVW 变换/MapScaler/UVW 清除/UVW 添加/投影）、**样条线修改器**（规格化样条线 `Normalize_Spline2` 等 14 项）、**拓扑与法线修改器**（切角/OpenSubdiv/加权法线/编辑法线/补洞/晶格/切片/四边化等）。
- **建模交互 vs 数值面板 (`□`)**：挤出、插入、倒角、切角、连接、桥接、焊接、轮廓及基础几何体等，主按钮进入视口交互拖动/绘制，右侧 `□` 打开对应 3ds Max 数值参数面板（几何体为原点直出）。

### 3. 五区全局热盒 & 一键切回原生四元菜单
- 默认在视口内按住 `` ` ``（Tab 上方反引号键，可在设置面板改为 `Space` / `F8` / `F9` 或禁用）呼出中/北/南/西/东五区热盒。
- 启动后在 **3ds Max 2026 顶部菜单栏** 自动添加专属按钮 **`MaxHotbox [热盒]`**，点击即打开配置面板，顶部提供 **[Maya 热盒模式] / [3ds Max 原生四元菜单]** 一键切换，切回四元菜单后立即卸载视口钩子。

## 多版本安装、卸载与自动更新（3ds Max 2026 / 2027）

从 [Releases](https://github.com/OMEN111111/3dsmax-hotbox/releases) 下载 `MaxHotbox_v0.1.5_Max2026_2027.zip`（或直接克隆本仓库）：

### 方式一：一体化插件管理器 `MaxHotbox_Manager.bat`（最推荐）
双击根目录下的 **`MaxHotbox_Manager.bat`**，在终端菜单中输入对应数字即可完成全部管理操作（自动隔离 2026 与 2027 插件包，互不干扰）：
- **`[1]` / `[2]` / `[3]`**：分别安装到 **3ds Max 2026**、**3ds Max 2027**，或一键安装到**全部支持版本**。
- **`[4]` / `[5]` / `[6]`**：分别卸载 **3ds Max 2026**、**3ds Max 2027** 或**全部版本**（可按版本独立选择是否清理个人配置与日志）。
- **`[7]`**：**检查插件更新** — 自动查询 GitHub 最新 Release 版本，支持一键下载 `.zip`/`.mzp` 到本地 `downloads/` 目录并自动校验 SHA-256 与解压。
- **`[8]`**：**更新已安装到不同版本的插件** — 自动识别已安装 MaxHotbox 的 Max 版本，支持在线拉取 GitHub 最新版或使用本地包更新，**完整保留个人自定义热盒配置**。
- 若 3ds Max 已打开不想重启，可在 Max 顶部点击 **`脚本 (Scripting) -> 运行脚本 (Run Script)...`** 选择 `Load_MaxHotbox_Now.ms` 立即热重载激活。

### 方式二：`.mzp` 单文件安装
打开 **3ds Max 2026** 或 **3ds Max 2027**，将 `MaxHotbox_v0.1.5_Max2026_2027.mzp` 拖入视口（若管理员权限拦截拖拽，改用 **`脚本 -> 运行脚本...`** 选择该 `.mzp` 文件），脚本会自动识别当前运行的 Max 版本并安装对应版本包后立即激活。

## 仓库目录结构

```text
3dsmax-hotbox/
├── MaxHotbox_Manager.bat      # 一体化多版本安装 / 卸载 / 检查更新 / 升级管理器
├── README.md                  # 项目说明与使用指南
├── CHANGELOG.md               # 版本更新记录
├── src/
│   ├── max_hotbox/            # 插件 Python 核心包 (兼容 Max 2026 Python 3.11 & Max 2027 Python 3.13 + PySide6)
│   └── maxscript/             # Max 2026 / 2027 MacroScripts、启动引导与卸载辅助脚本
└── packaging/                 # Autodesk .bundle 清单、.mzp、manager.ps1 与打包脚本
```

### 从源码自行打包
```powershell
python .\packaging\build_package.py
```
执行后会在本地 `dist/` 目录自动生成 `MaxHotbox.bundle/`、`MaxHotbox_v0.1.5_Max2026_2027.zip`、`MaxHotbox_v0.1.5_Max2026_2027.mzp`、`MaxHotbox_Manager.bat`、`manager.ps1`、`Load_MaxHotbox_Now.ms` 与 SHA-256 校验文件。
